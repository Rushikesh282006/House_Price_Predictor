# California House Price Prediction & Web Dashboard

An end-to-end Machine Learning web application that predicts California home values using a trained `RandomForestRegressor`. Built with **FastAPI**, **Scikit-Learn**, and a modern, responsive **Web Dashboard**.

---

## 🚀 Project Overview

This repository demonstrates a complete ML deployment pipeline:
1. **Exploration & Training**: Analyzes census data and trains a Random Forest regression model on the California Housing dataset.
2. **REST API**: Serves prediction endpoints with input validation via FastAPI and Pydantic.
3. **Web Dashboard**: Provides an interactive browser UI with single-property predictions, California sample presets, and batch CSV processing.

## 🧠 Machine Learning Model & Dataset

- **Dataset**: `sklearn.datasets.fetch_california_housing` (20,640 block groups from the 1990 California census).
- **Algorithm**: `RandomForestRegressor(n_estimators=200, random_state=42)`
- **Evaluation Metrics**:
  - **Mean Absolute Error (MAE)**: ~`$32,800`
  - **R² Score**: ~`0.805`
- **Output Multiplier**: The model predicts values in units of $100,000; the API converts them to actual USD currency values (`predicted_price = raw_prediction * 100,000`).

### Required Input Features

| Feature | Type | Valid Range | Description & Units |
| :--- | :--- | :--- | :--- |
| `MedInc` | `float` | `0 < x <= 55` | Median income in block group (in $10,000s; e.g. `3.5` = $35,000) |
| `HouseAge` | `float` | `0 < x <= 100` | Median house age in block group (years) |
| `AveRooms` | `float` | `> 0` | Average number of rooms per household |
| `AveBedrms` | `float` | `> 0` | Average number of bedrooms per household |
| `Population` | `float` | `0 < x <= 10000` | Block group population |
| `AveOccup` | `float` | `> 0` | Average household occupancy (people per home) |
| `Latitude` | `float` | `31 < x <= 42` | Geographic latitude coordinates (California) |
| `Longitude` | `float` | `-125 < x <= -114`| Geographic longitude coordinates (California) |

## 🛠️ Setup & Installation

### 1. Clone the repository and open PowerShell

```powershell
cd "path\to\House Price Prediction"
```

### 2. Create and activate a virtual environment

```powershell
# Create virtual environment
python -m venv venv

# Activate on Windows PowerShell
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### 4. Generate model files (if not present)

Due to file size limits, `.joblib` model artifacts may not be committed to GitHub. If `house_price_predictor.joblib` is not present, train it locally:

```powershell
python train.py
```

This generates `house_price_predictor.joblib` and `house_features.joblib`.

## 🌐 API Endpoints Specification

### 1. Web Dashboard
- **Route**: `GET /`
- **Response**: Serves `frontend/index.html` (the responsive valuation dashboard).

### 2. Service Health
- **Route**: `GET /health`
- **Response**:
  ```json
  {
    "status": "running",
    "model": "RandomForestRegressor",
    "avg_error": "$32800"
  }
  ```

### 3. Single House Price Prediction
- **Route**: `POST /predict`
- **Request Body** (`application/json`):
  ```json
  {
    "MedInc": 3.5,
    "HouseAge": 20.0,
    "AveRooms": 6.5,
    "AveBedrms": 1.2,
    "Population": 1200.0,
    "AveOccup": 2.5,
    "Latitude": 36.5,
    "Longitude": -119.5
  }
  ```
- **Response** (`200 OK`):
  ```json
  {
    "predicted_price": "$106,374",
    "confidence_range": "$73,574 to $139,174"
  }
  ```

### 4. Batch CSV Prediction
- **Route**: `POST /predict-file`
- **Input**: Multipart form-data with key `file` containing a `.csv` file.
- **Requirements**: CSV must contain columns: `MedInc`, `HouseAge`, `AveRooms`, `AveBedrms`, `Population`, `AveOccup`, `Latitude`, `Longitude`.
- **Response**: File download stream (`prediction.csv`) with the original columns plus a new `predicted_price_usd` column appended to each row.
- **Sample File**: Use [`test_file.csv`](file:///c:/Users/Rushikesh%20Jagtap/.vscode/VS%20Code%20files/Learning%20Machine_Learning/House%20Price%20Prediction/test_file.csv) to test this endpoint.

## 🎨 Web Dashboard Features

- **2-Column Responsive Input Form**: Clean parameter inputs with immediate boundary checks.
- **One-Click California Presets**: Quick-fill realistic data for:
  - 🌊 *Coastal Luxury* (High income, coastal SF/Bay Area)
  - 🏡 *Suburban Family* (Mid-tier suburban housing)
  - 🌲 *Central Valley* (Affordable inland housing)
- **Real-Time Client Validation**: Alerts users if coordinate or income values fall outside California ranges prior to sending API requests.
- **Batch CSV Drag & Drop / Upload**: Automatically dispatches batch jobs and downloads the output file.
